# TRELLIS Lite — MLinPL 2026

This is a reduced fork of [Microsoft TRELLIS](https://github.com/microsoft/TRELLIS) for the MLinPL 2026 tutorial **“Build Your Own 3D Scene: An Introduction to Gaussian Splatting.”** It contains the image-to-3D inference and rendering code needed by the workshop's TRELLIS notebook and memory benchmark. It intentionally omits training, Gradio, and most upstream examples/assets.

See [WORKSHOP.md](WORKSHOP.md) for the required repository layout, runtime dependencies, model weights, and submodule setup. The original project and its full documentation are available [upstream](https://github.com/microsoft/TRELLIS). Original license: [MIT](LICENSE).
